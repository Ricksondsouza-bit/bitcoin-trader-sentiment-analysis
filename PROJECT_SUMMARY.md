# Project Summary

## Bitcoin Market Sentiment and Trader Performance Analysis

This project analyzes the relationship between Bitcoin market sentiment and trader performance using Hyperliquid historical trading data and the Bitcoin Fear and Greed Index.

## What Was Built

- Reusable Python source modules for loading, cleaning, merging, analysis, and visualization.
- A Jupyter notebook documenting all project phases.
- Processed datasets for analysis.
- EDA summary reports.
- Static visual charts.
- A Streamlit dashboard.
- A final written report.

## Main Deliverables

- Notebook: `notebooks/trader_sentiment_analysis.ipynb`
- Dashboard: `dashboard/app.py`
- Final report: `outputs/reports/final_project_report.md`
- Report CSV files: `outputs/reports/`
- Chart PNG files: `outputs/charts/`

## Portfolio Talking Points

- Built an end-to-end data science workflow from raw CSV files to dashboard.
- Used `pathlib`, reusable functions, and a modular `src/` structure.
- Preserved raw data and saved processed outputs separately.
- Created merge-quality checks to identify unmatched sentiment rows.
- Summarized performance by sentiment, direction, and coin.
- Created visual charts and a local interactive Streamlit dashboard.

## Important Limitation

This is a descriptive analysis. It does not prove causation and should not be interpreted as financial advice.
